# Bienvenidos!

Repositorio oficial del curso. Acá encontrás el material de cada módulo:
comandos comentados, cheatsheets y enunciados de challenges.

---

## Cómo usar este repo

Cada módulo tiene su propia carpeta con:

- `README.md` — overview del módulo y qué vas a aprender
- `clase-N-comandos.md` — todos los comandos explicados flag por flag
- `clase-N-cheatsheet.md` — referencia rápida para tener abierta mientras practicás
- `challenge.md` — enunciado del challenge del módulo (se publica al final de la última clase)

## Reglas del curso

**Regla de oro:** Todo lo que aprendés acá se practica con autorización
o contra objetivos diseñados para eso. Nunca contra sistemas sin permiso explícito.

**Entorno recomendado:** Kali Linux en VM propia.

**Dudas y entregas:** GitHub Discussions del repo.

---

## Contexto narrativo

Durante el curso trabajamos como consultores recién contratados para auditar
**Nexus Financial S.A.** — una fintech latinoamericana ficticia.
Cada técnica que aprendés tiene un propósito concreto dentro de ese engagement.

```
Fases del pentest que vamos a cubrir:

  RECON  →  ACCESO  →  POST-EX  →  REPORTE
  [ M1 ]    [ M2+ ]    [ M3+ ]     [ M4+ ]
```
